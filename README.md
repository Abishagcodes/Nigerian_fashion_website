Nigerian Fashion Website

A responsive Nigerian fashion e-commerce website inspired by traditional Nigerian fashion and contemporary African style.

🌐 Live Demo

https://abishagcodes.github.io/Nigerian_fashion_website/

✨ Features

- Responsive design for different screen sizes
- Modern fashion-focused landing page
- Product collection showcase
- Navigation menu
- Brand story / About section
- Contact section
- Clean and user-friendly layout
- Nigerian/African-inspired visual style

🛠️ Built With

- HTML5
- CSS3
- JavaScript

📸 Preview

The website showcases a Nigerian fashion brand concept with a modern interface designed to present clothing collections and brand information clearly.

🎯 Project Purpose

This project was created to practice building a complete business website from scratch while combining responsive web design, visual presentation, and user-friendly navigation.

📚 What I Learned

While building this project, I improved my understanding of structuring webpages with HTML, styling layouts with CSS, creating responsive designs, and adding interactive elements with JavaScript.
